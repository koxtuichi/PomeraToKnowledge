# ホーム画面「最近前に出てきたテーマ」計画

## 目的

日記分析のホーム画面に、以前と比べて最近よく現れる価値観・関心テーマを表示する。断定的に「価値観が変わった」と言わず、日記上の観察として「最近前に出てきたテーマ」を提示する。

## 表示内容

- 最大3件のテーマを表示する
- 各テーマはカテゴリ、変化ラベル、根拠サマリ、直近日記の短い例、比較期間、根拠強度を持つ
- データがない場合はカード自体を非表示にする

## 実装方針

- `llm_graph_builder.py` で日記ノードの時系列を比較し、`value_shift_topics` を分析JSONへ追加する
- 直近14日とそれ以前60日を比較し、日記数が少ない場合は最新5件とその前20件の比較へフォールバックする
- LLMの人格推定ではなく、カテゴリ別キーワードの出現変化と日記例から観察トピックを生成する
- Cloud Functions側の同名ビルダーにも同じロジックを反映する
- `index.html` のホーム画面に横長カードとして表示する

## 注意点

- 心理診断や人格断定を避ける
- 家族名、金額、健康状態などの機微情報を長く露出しない
- 1文字キーワードや一般語による誤検出を避ける
